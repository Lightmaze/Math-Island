# 数学岛屿教师指南

[English](teacher-guide.en.md) · [课程契约](curriculum.md) · [16 个基础实验](laboratories.md) · [8 个专用实验](advanced-laboratories.md)

本指南用于 **24 座已编写课程的岛屿**，围绕应用中已有的 **4 条教学路线**与图谱中已记录的 **21 条文献桥**，组织课堂探索和研究阅读。所列时间是备课估算，不是实测完成时间或学习效果证据。高级数学仍然属于课程内容：有限实验把一个具体问题显现出来，相关定理、证明和研究工具则保留自身的完整范围。

本体图谱包含 21,741 条来源索引记录，其中 24 条具有本批专门编写的教育窗口。不能把其他来源条目自动称为已完成的课程。日志标记记录一次操作或学习者的文字，不代表已经理解、答案正确或通过形式化证明。

## 课前准备

打开教育应用，选择授课语言，并实际试用准备使用的控件。下文课程链接使用 canonical 仓库 [Lightmaze/Math-Island](https://github.com/Lightmaze/Math-Island) 对应的 Pages 地址 `https://lightmaze.github.io/Math-Island/`，保留具体岛屿、实验和语言的 hash 路由。公开发布与链接可用性仍待 root 在部署后核验；此处更新链接不代表已经完成发布核验。把 `lang=zh` 改为 `lang=en` 即选择英文。

结合图像、数值读数和条件说明授课。不要让任务只能凭颜色完成：使用点名、边名、系数、正负号和读数。键盘可以操作原生控件；纸面课堂可以使用相同的公式和表格，但不会复现交互。切换实验前记录参数，因为局部实验状态可能重置。

请每组保留一页简短的证据记录：

| 项目 | 需要记录什么 |
|---|---|
| 对象与假设 | 实际使用的集合、空间、域、分布、算子或上下文，以及系数和边界条件。 |
| 动作与观察 | 改了哪个控件，修改前后的参数值，以及观察到的输出。 |
| 主张与证据 | 正在检验什么；区分截图、有限精确计算、代数推导和文献定理。 |
| 失败与延伸 | 一个反例或缺失的前提，以及还需要阅读的来源或完成的论证。 |

“观察到了”“计算得到了”“在这个论证中证明了”“文献陈述了”回答不同的问题。残差接近零是计算证据；基于明确恒等式的短证明可以在其前提下建立数学结论。两者都不能改称证明助手认证。

## 让数学对象决定岛的生态

当生态语言保留了数学区别时，它才有教学作用。礁格可以表示整数，重叠树冠可以表示两个开集。教师应当先能说明对象、允许的操作和约束，再解释比喻。

| 生态 | 编码的操作 | 需要追踪的量或约束 |
|---|---|---|
| 随潮退去的素数礁格 | 从当前质数的平方开始排除其合数倍数 | 保留质数本身；停止条件依赖不超过 √N 的质因子。 |
| 椭圆曲线的枝条与反射交点 | 在指定非奇异三次曲线上做割线或切线加法 | 点须满足同一方程；单位元是无穷远点。 |
| 理想沉积层与素谱根系 | 取理想和、交；选择基本开集 D(f) | ℤ 中的 gcd/lcm；素理想点不是环元素。 |
| 重叠树冠 | 限制并胶合相容局部截面 | 整个重叠区上的一致性，以及胶合的唯一性。 |
| 洞窟边与三角面 | 施加边界算子，把循环模去边界 | ∂₁∂₂=0；Betti 数使用指定系数域上的秩。 |
| 覆盖梯田 | 从固定起点提升一条路径 | 累积角度；底空间闭路不保证提升闭合。 |
| 谐波潮汐与热流纹理 | 叠加频率分量，或按指定速率衰减 | 傅里叶系数、扩散系数、周期性和本征值尺度。 |
| 森林枝条 | 选择图拟阵的地集元素 | 森林独立性、秩，以及最小依赖的简单圈。 |
| 运输水道 | 在指定成本下分拆并搬运质量 | 两侧边际与总成本；水道宽度表示运输质量。 |
| 类型观测台 | 在上下文中应用推导规则 | 输入输出类型匹配；上下文假设不是闭合证明。 |

装饰性地貌不构成额外的数学数据。像素距离不能代替图的边权或定义有限域距离。岛屿在海图上相邻，不表示它们之间有定理。教学路线属于编辑安排；文献桥必须由明确来源支持。

## 四条现有路线：可执行教案

### 1. 频率与热 — `waves-and-heat`

**建议安排：**90 分钟；学生已接触三角函数、导数和矩阵乘法。研究延伸需要傅里叶分析与算子理论。使用[复流海峡](https://lightmaze.github.io/Math-Island/#view=islands&island=complex-current&lab=1&lang=zh)、[傅里叶潮汐](https://lightmaze.github.io/Math-Island/#view=islands&island=fourier-tide&lab=1&lang=zh)、[热流海岸](https://lightmaze.github.io/Math-Island/#view=islands&island=heat-shore&lab=1&lang=zh)、[本征态灯塔](https://lightmaze.github.io/Math-Island/#view=islands&island=spectral-lighthouse&lab=1&lang=zh)。

1. **0–15 分钟：旋转是一种运算。**把非零复乘子的模设为 1，改变辐角，记录标记点的像。在纸上计算连续乘以 i 两次和四次的结果，再观察模为 0 时的塌缩。讨论关于角度的哪些结论需要非零导数或乘子。
2. **15–35 分钟：基可以表示形状。**把奇次谐波数从 1 增加到 25，分别记录平坦区和跳跃附近的表现。区分采样最大值与精确上确界。解释为什么连续有限和不可能一致收敛到不连续方波。
3. **35–60 分钟：算子对不同模态的作用不同。**在热流海岸设置正的三倍频振幅，比较 t=0 与稍后时刻。对显示的公式求导，验证 `u_t=u_xx`。说明 `sin(3x)` 的衰减指数为什么是 9 而不是 3，以及平均值为何保持零。
4. **60–80 分钟：边界和尺度会改变本征问题。**选择有限 Dirichlet 矩阵的不同模态，利用 `sin((j−1)θ)+sin((j+1)θ)=2cosθ sin(jθ)` 推出显示的本征值。比较不同矩阵维数前，先讨论未乘入的 `h⁻²` 因子。
5. **80–90 分钟：比较模型。**提交一张表，分别列出对象、操作、边界条件，以及一个不能原封不动搬到下一实验的结论。

**开放问题：**如果改变边界条件，模态论证的哪一部分仍可能保留？学生可以提出猜想并定位缺失的本征基论证，不要求凭空解决一个未指定的 PDE。

**保持区别：**这条路线没有把波动方程的解转化为热。热模型是周期的，矩阵模型采用 Dirichlet 端点；共同线索是谱分解，而不是认定两个算子相同。文献桥 015 提供另一种热方程的概率表示，并有明确的扩散系数约定。

### 2. 局部与整体 — `local-to-global`

**建议安排：**90 分钟；已知基本环运算、函数和有限线性代数。概形、层上同调和导出构造属于研究延伸。使用[理想沉积湾](https://lightmaze.github.io/Math-Island/#view=islands&island=ideal-basin&lab=1&lang=zh)、[素谱湿地](https://lightmaze.github.io/Math-Island/#view=islands&island=spectrum-marsh&lab=1&lang=zh)、[层的云冠](https://lightmaze.github.io/Math-Island/#view=islands&island=sheaf-canopy&lab=1&lang=zh)、[同调洞窟](https://lightmaze.github.io/Math-Island/#view=islands&island=homology-cavern&lab=1&lang=zh)。

1. **0–20 分钟：算术变成结构。**把理想生成元设为 4 和 6，列出和、交中的若干元素。用 `2=6−4` 解释现象，再通过整除和 Bézout 等式证明 gcd/lcm 公式。说明并集为什么不是理想和。
2. **20–35 分钟：点集不能恢复环。**比较 n=6 与 n=12 的素谱，令 f=0、f=1，解释 D(0)、D(1)。两者都有两个点；在纸上比较幂零元：模 12 的 6 非零且平方为零，而 ℤ/6ℤ 是约化环。
3. **35–55 分钟：相容要求在开集上相等。**调节第二片一次函数，使两条直线只在一个点相交，说明为何不能胶合。匹配系数后，证明并集上的连续函数唯一。两个不同点上的检查对这些一次函数足够，但不是任意连续截面的相容性判据。
4. **55–75 分钟：循环也可能是边界。**比较填满、有洞、切开、分离四种复形，分别选择一个三角形组成的二维链和全部三角形之和。记录 β₀、β₁、∂₁∂₂，解释 F₂ 中的相消。给出一个图上可见但同调类为零的闭环。
5. **75–90 分钟：明确哪里换了对象。**分别制作四张对象卡，指出有限环、实数区间和单纯复形并不是同一个空间。说明若要调用联系层与上同调的定理，还需要哪些构造。

**开放问题：**只保留概形的拓扑点，会丢失哪些信息？区分带环层的空间与没有标签的有限点集，不把点数相同当作同构。

**阅读：**文献桥 013 是代数闭域上的根理想与仿射代数集合对应。它没有断言实验中的实零点图、有限商环素谱和连续函数层是同一个对象。

### 3. 独立性与结构保持 — `independence`

**建议安排：**80 分钟；已知图和函数的基本语言。高级阅读需要拟阵与分次代数。使用[图的桥群](https://lightmaze.github.io/Math-Island/#view=islands&island=graph-bridges&lab=1&lang=zh)、[拟阵森林](https://lightmaze.github.io/Math-Island/#view=islands&island=matroid-forest&lab=1&lang=zh)、[对称林](https://lightmaze.github.io/Math-Island/#view=islands&island=symmetry-grove&lab=1&lang=zh)、[函子港](https://lightmaze.github.io/Math-Island/#view=islands&island=functor-harbor&lab=1&lang=zh)。

1. **0–20 分钟：先说明优化目标。**目标点不变，比较 BFS 与 Dijkstra，再改变 E–H 边权重复实验。分别记录边数和总权。解释等非负权为何保证两种目标一致，也说明非等权不意味着每个实例都必然得到不同路线。
2. **20–40 分钟：独立性不等于边数。**在 K₄ 中选一个三角形，保留第四个孤立顶点，计算 `r(A)=4−c(A)=2`，再与三边生成树比较。在两棵树之间找一次有效基交换，并找一次会产生环的无效交换。
3. **40–55 分钟：保持正方形结构。**比较四分之一旋转和反射的两种复合顺序，用带标签顶点给出不交换的见证。区分正方形的八个对称与四个标签的全部 24 个排列。
4. **55–70 分钟：把“保持”说清楚。**在有限偏序模式中比较保序和反序选择；在有限集合方块中检查每个输入的两条复合路径。若不相等，给出具体输入见证。
5. **70–80 分钟：拆开三种独立性。**分别定义图拟阵的独立边集、概率独立变量和线性无关向量。这里只有第一种独立性在本实验中实现。提出一个有来源支持的连接，而不是只凭同一个词认定三者相同。

**开放问题：**两个结构之间的映射究竟需要保持什么？提出一个定义，用小反例检查它。路线没有宣称四个实验已经共同实现了一个从头到尾的函子。

**阅读：**文献桥 003 为无自环拟阵构造 Chow 环与 Hodge 理论关系。K₄ 图像不能证明一般定理；一般拟阵不必是图拟阵，也不必可表示。让学生追踪证明新建了什么对象，以及它把什么不等式传回组合论。

### 4. 随机、平均与运输 — `chance-and-motion`

**建议安排：**90 分钟；已知期望、方差和初等微积分。Feynman–Kac 与合成曲率需要后续读书会。使用[布朗三角洲](https://lightmaze.github.io/Math-Island/#view=islands&island=brownian-delta&lab=1&lang=zh)、[均值潮汐](https://lightmaze.github.io/Math-Island/#view=islands&island=mean-tide&lab=1&lang=zh)、[热流海岸](https://lightmaze.github.io/Math-Island/#view=islands&island=heat-shore&lab=1&lang=zh)、[运输沙洲](https://lightmaze.github.io/Math-Island/#view=islands&island=transport-sandbar&lab=1&lang=zh)。

1. **0–20 分钟：随机对象和样本群统计量不同。**比较一条与多条 Brownian 路径，细化时间网格并观察终点统计量。说明 `Var(B_t)=t`，明确逐时刻的 ±2√t 带限制了什么、没有限制什么。
2. **20–40 分钟：显式更换样本空间。**均值潮汐使用 Bernoulli 试验，不是把前一实验的 Brownian 位置连续取平均。延长同一个样本前缀，找一次均值远离 p 的更新。若显示 Hoeffding 带，说明保证针对固定 n，而非整条路径的同时覆盖。
3. **40–60 分钟：推导一个条件匹配的连接。**热实验的扩散系数是 1，标准 Brownian 运动的生成元是 ½Δ。取 V=0 和实验中光滑周期初值，可用 `u(t,x)=E[f(x+√2 B_t)]`；若在圆周上解释，函数自变量按 2π 取模。利用高斯特征函数得到正弦模态的衰减 `e^(−n²t)`。这是连接两个已明确模型的纸面推导，不是声称两界面共享了一次模拟。
4. **60–80 分钟：守恒是约束。**移动目标测度的位置并调整质量，核对运输计划的两侧边际，累计显示的各项成本。寻找同一个源点的质量需要分往不同目标的情形。
5. **80–90 分钟：审查类比。**提交三句话：一个核对过的有限计算，一个概率模型中的精确计算，以及连接运输与曲率还需要的一条定理。

**开放问题：**何时两个不同运输计划可能有相同成本？探索一个有限例子，区分“存在单调最优计划”与“最优计划唯一”。

**保持区别：**热实验可以出现负值，因为它表示温度偏差，不是概率密度。运输实验采用一维绝对距离成本，属于 W₁ 设置；Lott–Villani 文献桥采用 W₂ 位移凸性框架。屏幕中的 W₁ 计划不能据此证明曲率下界，也不能替代一般热流的梯度流定理。

## 三个补充工作坊覆盖其余岛屿

这些是新增的教师活动方案，不是悄悄加入应用四条路线列表的其他路线。

### A. 一条规则凭什么能用 — 60 分钟

使用[素数礁](https://lightmaze.github.io/Math-Island/#view=islands&island=prime-reef&lab=1&lang=zh)、[有限域环礁](https://lightmaze.github.io/Math-Island/#view=islands&island=finite-field-atoll&lab=1&lang=zh)、[类型观测台](https://lightmaze.github.io/Math-Island/#view=islands&island=type-observatory&lab=1&lang=zh)。适合作为初次证明工作坊，有限域记号需要明确介绍。

- **20 分钟：筛法。**完成 2、3、5 的筛轮后检查 49。证明不超过 N 的合数具有不超过 √N 的质因子，解释保留 p 和从 p² 开始的理由。
- **20 分钟：插值。**在一个支持的素数域中先保留两个、再保留三个互异求值点。在纸上证明次数小于 3 时的唯一性：两个候选多项式之差有三个互异根。说明重复位置或任意错误值为什么改变了问题。模 6 是反驳“每个模数都给出一个域”的书面例子，界面没有把它作为域选项。
- **20 分钟：类型。**改变参数类型并启用组合，写出准确的函数应用规则及包含 f、g、x 的上下文。解释为什么带假设的推导没有为任意类型提供闭项。

**收集产物：**三个短论证，每个指出不可缺少的前提。**研究延伸：**文献桥 005、009、020、021。初等筛法没有替代 Green–Tao 迁移论证，类型应用窗口也没有替代完整证明助手。

### B. 几何改变时，哪些信息保留 — 100 分钟

使用[零点群峰](https://lightmaze.github.io/Math-Island/#view=islands&island=zero-set-peaks&lab=1&lang=zh)、[椭圆曲线园](https://lightmaze.github.io/Math-Island/#view=islands&island=elliptic-garden&lab=1&lang=zh)、[覆盖梯田](https://lightmaze.github.io/Math-Island/#view=islands&island=covering-terraces&lab=1&lang=zh)、[曲率山脊](https://lightmaze.github.io/Math-Island/#view=islands&island=curvature-ridge&lab=1&lang=zh)。如果先修知识差异较大，可拆成两次活动。

- **25 分钟：方程与奇点。**比较 `xy=c` 与 `c=0`，用 `F=F_x=F_y=0` 定位相交奇点；比较半径为零与非零的实圆。指出实图忽略了哪些复点和射影完备化信息。
- **25 分钟：有条件的运算法则。**选择椭圆实验的割线、切线、互逆和奇异预设，代入方程核对给定点，计算 `y²=x³−x+1` 上的割线和点。区分 O 与 (0,0)。不要要求任意拖动点：此界面有意采用满足条件的预设。
- **25 分钟：提升整条路径。**设 n=3，让基路径走一圈和三圈，记录提升端点。由选定起点推导 `e^(it/3)`，解释每圈把角度重置为零为什么会丢失信息。
- **25 分钟：局部与总曲率。**比较四面体、八面体与环面网格，计算 V、E、F，区分总角亏与逐顶点角亏。由 `3F=2E` 和面角总和 πF 推出闭合三角网格公式。光滑定理需要另述假设和另行论证。

**收集产物：**方程核对、一次加法计算、提升公式、离散不变量推导。**阅读：**文献桥 001、012、013、014、018。这些链接支持不同的数学构造，不构成把所有场景等同起来的一条无名等价。

### C. 三种“最终会怎样” — 60 分钟

使用[Cantor 海岸](https://lightmaze.github.io/Math-Island/#view=islands&island=cantor-coast&lab=1&lang=zh)、[梯度盆地](https://lightmaze.github.io/Math-Island/#view=islands&island=gradient-basin&lab=1&lang=zh)、[均值潮汐](https://lightmaze.github.io/Math-Island/#view=islands&island=mean-tide&lab=1&lang=zh)。适合引入极限；概率部分在相关假设已经讲清时加入。

- **20 分钟：长度缩小。**推导 Cantor 有限阶段的区间数与总长度，比较“总长度趋于零”和“极限集合有限”。用无限 0/2 三进制选择讨论基数，明确屏幕上每个有限阶段仍含非退化区间。
- **20 分钟：收缩。**推导梯度迭代的两个乘子，令 λ=4 比较稳定和不稳定步长。表述“对所有初始点都收敛”的严格条件 `0<η<2/λ`；端点可能有模为 1 的乘子。特殊初值可能把不稳定坐标设为零，所以量词不能省。
- **20 分钟：几乎处处收敛。**比较 Bernoulli 均值与确定性的乘子判据，把一句含糊陈述改写成带量词的陈述，指出有限前缀为何不能决定几乎处处收敛。

**收集产物：**一个极限对象的定义、一个精确稳定性论证和一条经过修正的概率陈述。不要因为三张图看上去都在“稳定”，就把三种极限混为一谈。

### 四次研究读书会

每次可安排约 90 分钟，并预留课外来源阅读。不同小组选择不同文献桥，不要求在四次讨论中重现 21 篇证明。

1. **证明创造了什么对象。**比较 001、002、003。每组说明新建的表示、辅助函数或代数，证明要求它满足什么性质，以及哪个定理使用这些性质。
2. **迁移需要哪些假设。**比较 005、006、007、016。画出假设记录表，指出一次不合法推广会从哪一步进入。这个示意图是阅读工具，不是新增核心图边。
3. **从存在走向程序或验证。**比较 004、009、020、021，拆开存在性、计算成本、错误模型、可靠性和正确性。去掉一个指定前提，要求给出失败例子或确切缺口。
4. **分类、不变量与信息丢失。**按小组知识选择 010–015、017–019 和 008。判断每条桥属于对应、不变量恒等式、界、表示还是迁移定理，说明反向推理为什么可能失败。

交付物是一份有来源定位的阅读笔记：准确主张、假设、构造、证明位置、尚未解决的一步，以及学生自己实际检查的范围。它可以包含失败尝试和缺失先修知识。不能用成功的初等演示替换未完成的高级证明，然后报告研究定理已经完成。

## 怎样提出一座新主题岛，同时保持本体独立

从数学对象和真实问题出发。值得补充的缺口包括明确的重抽样过程、多项式划分的参数空间、指定拟阵的 Chow 环计算，或有限 sum-check 对话实例。把一张装饰性网络图换成新领域名称，并不足以形成新课程。

准备一个只属于教育层的提案，至少包含：

1. 稳定的拟用教育 ID 和真实已有核心引用；若核心尚未收录，就明确标注外部来源。不要为显得已经接入图谱而虚构核心 ID。当前发布课程的契约要求已有核心主引用；如果没有，就先保留外部来源提案草稿，待明确的教育层适配或独立本体补录经过审读后再接入。
2. 精确对象、状态变量、操作、允许参数范围、不变量和失败情形，说明哪些量精确计算、哪些量数值近似。
3. 视觉字典：每个图形标记对应何种实体，每个控件对应何种操作，每个输出的量和尺度是什么，以及图像不可避免地省略了什么。
4. 中英文说明、三个实质步骤、一个开放问题、一个可证伪主张及答案，以及带来源的研究延伸。
5. 有鉴别力的检查，例如边际守恒、链恒等式、次数界或拒绝一个错误前提，并另做可用性审查。
6. 声明教学坐标、进度与实验状态留在 `education/`。不改已有核心节点、关系、分类和验证标签。若需校勘核心，另附证据与精确位置提出修订。

按[课程契约](curriculum.md)审读提案。数学深度可以先增长，地图不必急于多一个图标。评价应检查活动产生的推理材料和模型正确性；出勤、点击与日志标记本身不能证明学习已经发生。
