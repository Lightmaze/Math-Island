# Connections: concept-to-production visual evidence / 联岛实验视觉核验

The production workbench preserves the paper, teal and copper identity and the compact directory / paired figures / controls / mathematical conditions / saved observation sequence. It is a functioning educational experiment surface, not a raster reproduction of the concept. The differences below are intentional and visible; no numerical fidelity score is claimed.

- Concepts inspected with `view_image`: [desktop](connections-concept-desktop.png), [mobile](connections-concept-mobile.png). Layout and copy contract: [connections-visual-contract.md](connections-visual-contract.md).

Its production index SHA-256 is **`953216d4164fa281000de240df983c97c77523c2107907ff7ddc68bf3e37ed20`**. The targeted follow-up captured **320 px Chinese, 320 px English and 1506 px English**, checked all their controls and page widths, and replaced the affected D₄ evidence. Other experiment screenshots are retained from the preceding, visually identical build; this is not a claim that every screenshot was recaptured after a CSS-only correction.
- [connections-visual-check.json](connections-visual-check.json) contains the original capture measurements and a separate `finalPatchVerification` with the last build's measurements and timestamps. The scope and provenance are explicit.
- Captures used isolated Chromium contexts and temporary local static servers. Each server was closed. The browser exposed no page or console errors in these checks. No preview application or temporary production route was added.
- Screenshots were inspected using `view_image`, including the desktop and mobile first screens, the full desktop reading surface, the saved-observation area, individual 320 px figures for all five other relationships, the full six-edge K₄ caption, and the final Chinese/English D₄ controls. Long-page screenshots were taken after visiting the related-lessons section so its ordinary lazy-loaded island artwork was visible, then returning to the top.
