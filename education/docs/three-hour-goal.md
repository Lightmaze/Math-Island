# 数学对象生态教育模块：三小时工作目标

工作窗口：2026-10-22 13:12–16:12 UTC。目标是交付可实际操作、经过数学与浏览器核验的独立教育模块。

## 可验收交付

1. 一份可缩放、可检索、可用键盘访问的完整来源图谱视图，保留 21,741 个实际节点及其关系类型。
2. 覆盖 12 个海域的 24 座策展教学岛；每座岛有独立数学对象、生态映射、学习动作、适用范围、问题与进阶方向。
3. 24 类可操作数学对象实验；图像和操作由明确模型产生，参数变化带来真实的几何、代数或数值变化。
4. 桌面与手机两个可用界面，搜索/筛选、岛屿阅读、对象实验、文献入口、学习笔记、导出与可分享链接。
5. 数学模型测试、核心文件不变性核验、真实浏览器操作与视觉检查；保存代码、数据契约与复核记录。

教学覆盖与本体覆盖分别计数。24 座深度教学岛不冒充全部 21,741 个条目均已完成课程建设。教学生态描述数学对象和操作；二维布局与景观形态不声称表达数学价值、难度或逻辑距离。

## 架构边界

- 所有代码、教学内容、派生索引、构建输出和证据都位于 `education/`。
- `docs/core-baseline.json` 固定开发前的 7,314 个仓库文件及其 SHA-256；教育实现不改写这些文件。开发中上游另行修正根 README 名称，发布保留此修改，以 `docs/publication-base.json` 记录新上游基线。
- 图谱节点由 `coreId` 引用。教学岛有自身 ID、版本、语言内容与生态布局；不复用或改写本体坐标。
- 全图视图使用单独构建的只读紧凑索引，记录核心提交与输入哈希。课程与图谱各自可独立更新；缺失引用由校验器指出。
- 笔记与探索记录保存在学习者自己的浏览器，并提供 JSON/Markdown 导出。浏览器不具备对核心图谱的写入接口。

## 分工与审查

- 主代理：目标、应用架构、界面集成、状态与笔记、浏览器核验、持久化。
- `education_curriculum`：24 岛内容、真实核心 ID、双语课程与条件。
- `education_labs`：16 类基础与结构对象实验、模型测试。
- `education_advanced`：8 类高级对象实验、模型测试。
- `education_atlas`：全量只读索引、Canvas 图谱、检索与可访问列表。
- `education_art`：桌面/手机视觉方案、数学生态图形与设计契约。
- `education_review`：独立数学、契约、隔离与操作复核。

## 技术设计

React + Vite + TypeScript。全图由一个 Canvas2D 实例绘制，DPR 至多为 2，视口外节点裁剪，停止操作时不持续重绘；文字、控制器与检索结果使用 HTML。教学岛地图与数学对象使用 SVG，保证缩放、语义标注及每个操作的数学解释。整个产品采用静态文件分发，不依赖远程 AI 或服务端数据库。

URL 保存视图、语言与选中岛屿；浏览器本地存储保存笔记与已观察记录。缩放控件和列表选择提供拖拽/悬停的替代路径。小屏幕显示纵向图面和底部阅读面板，重要信息不依赖悬停。

视觉设计以自然史图谱的细线、明确对象与空间层次组织阅读；真实数学图形直接用代码生成，不把生成式概念插画当作证明或数值图。
