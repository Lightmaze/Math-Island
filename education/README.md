# 数学群岛 · 对象生态教育模块

[中文](README.zh-CN.md) · [English](README.en.md) · [打开站点 / Open site](https://mathcups-mathematical-islands.ljie5996.chatgpt.site) · [下载静态成品 / Download static site](https://github.com/Lightmaze/Math-Island/archive/refs/tags/education-static-v0.2.0.zip)

把数学对象的运算、结构与不变量变成可以探索的岛屿生态。24 座原创双语对象课堂，连接 21,741 个真实来源条目的完整数学图谱。

Mathematical objects become habitats you can explore through their operations, structure, and invariants. Twenty-four authored bilingual explorations connect to a complete atlas of 21,741 source-backed entries.

**0.2.0 新增六个联岛工作台**：傅里叶与热流、图与同调、复数与覆盖、运输与分布函数、理想与零点、对称与表示。24 座对象课堂、21,741 条本体条目和 21 条既有文献桥梁仍分别保留其真实范围。

**Version 0.2.0 adds six connection workbenches**: Fourier–heat, graph–homology, complex maps–coverings, transport–CDFs, ideals–zeros, and symmetry–representations. The 24 lessons, 21,741 core entries and 21 existing literature bridges remain distinct counts.

联岛实验可在本机保存参数、计算结果和观察文字，支持 JSON / Markdown 导出与 JSON 导入，最多 500 条。分享只分享实验入口，不包含当前参数或私人记录；打开入口不会自动恢复已存参数。

Save parameters, computed results and observations locally; export JSON or Markdown and import JSON, up to 500 records. Sharing sends only the experiment entry, without current parameters or private records. Opening an entry does not restore saved parameters automatically.

本目录是独立教育模块。本体图谱可以继续成长；课程、地貌与教学路径不写回本体节点、关系或类型标注。

This directory is an independent education module. The core atlas can continue to grow; lessons, scenery, and teaching itineraries do not write back to its nodes, relations, or type annotations.

```bash
cd education
npm ci
npm run dev
```
