# 数学群岛 · 对象生态教育模块

[中文](README.zh-CN.md) · [English](README.en.md)

把数学对象的运算、结构与不变量变成可以探索的岛屿生态。24 座原创双语对象课堂，连接 21,741 个真实来源条目的完整数学图谱。

Mathematical objects become habitats you can explore through their operations, structure, and invariants. Twenty-four authored bilingual explorations connect to a complete atlas of 21,741 source-backed entries.

本目录是独立教育模块。本体图谱可以继续成长；课程、地貌与教学路径不写回本体节点、关系或类型标注。

This directory is an independent education module. The core atlas can continue to grow; lessons, scenery, and teaching itineraries do not write back to its nodes, relations, or type annotations.

```bash
cd education
npm ci
npm run dev
```

Read the [Chinese guide](README.zh-CN.md) or [English guide](README.en.md) for exploration, mathematical scope, rebuilding and contribution.
