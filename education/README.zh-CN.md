# 数学群岛 · 对象生态教育模块

[English](README.en.md) · [仓库与本体图谱](../README.zh-CN.md)

[打开数学群岛](https://mathcups-mathematical-islands.ljie5996.chatgpt.site)（当前仅创建者可访问） · [下载公开静态成品](https://github.com/Lightmaze/Math-Island/archive/refs/tags/education-static-v0.2.0.zip)。静态包解压后，在其目录运行 `python -m http.server 8000`，即可从 `http://localhost:8000` 使用，不需要 Node 或构建。GitHub Pages 尚未启用，原因及启用方法见[部署记录](docs/deployment.md)。

这是 MathCups 数学群岛的独立教育模块。岛的生态由数学对象的结构来组织：理想体现为整除的嵌套，层体现为局部对象的兼容胶合，热流体现为不同频率的衰减。地貌是教学隐喻，实验图形和数值由明确的数学模型计算。

当前交付版本：**0.2.0**。本轮新增六个联岛工作台与可备份的实验记录；[一小时冲刺记录](docs/one-hour-sprint.md)区分实际实现、验证与部署状态。

## 可以探索什么

- **24 座双语对象课堂，12 个领域。** 每座都有对象定义、生态解释、实际可操作的模型、三步探索、反思问题、反例或边界、出处和进阶阅读。
- **6 个双语联岛实验。** 在同一份数学状态上同时观察两种结构，核对恒等式、构造或表示；联系的条件和失效边界随实验呈现。
- **完整 21,741 条目图谱。** 保留本体坐标与稳定 ID，可搜索、平移、缩放、按域筛选、浏览实际相邻关系和证据，并导出视图。
- **21 条已有文献桥梁。** 可阅读跨领域联系的机制、条件、结论与局限，并定位两端。
- **4 条策展学习路径。** 频率与热流、局部与整体、独立性与结构、随机性与运动。虚线只表示课程顺序，不添加证明依赖或历史因果关系。
- **结构化联岛实验记录。** 保存当前参数、计算结果和自己的观察文字；支持 JSON / Markdown 导出与 JSON 导入，最多保存 500 条。
- **学习者自己的航记。** 本地保存、Markdown 导出、JSON 备份与导入。应用本身无账户和遥测；笔记不会上传。当前私有 Sites 入口另有 ChatGPT 登录门，本地或自行托管无需该登录。

24 是原创教学岛数量；6 个联岛实验是额外的教育工作台，不增加本体条目或既有 21 条文献桥梁的数量。21,741 是当前来源快照中的数学条目数量。后者包含概念、定义、方法、问题与数学陈述，并非 21,741 个独立理论，也不是每项都已人工编写课程。现有来源约 68% 来自 Stacks，覆盖并不均衡。

## 岛上有哪些数学对象

| 海域 | 两座对象课堂 | 实际模型 |
| --- | --- | --- |
| 数论与算术 | 素数礁、椭圆曲线园 | Eratosthenes 筛；实三次曲线的割线、切线和单位元 |
| 代数与结构 | 对称林、有限域环礁 | 正方形 D₄；素域上的多项式插值与擦除恢复 |
| 交换代数 | 理想沉积盆、素谱湿地 | ℤ 中主理想；Spec(ℤ/nℤ) 的素点和基本开集 |
| 代数几何 | 零点群峰、层的云冠 | 圆、双曲线和三次零点集；区间上局部连续函数的胶合 |
| 范畴与同调 | 同调洞窟、函子港 | 有限三角复形上的链和边界；有限范畴中的结构保持 |
| 几何与拓扑 | 覆盖梯田、曲率山脊 | 圆周 n 重覆盖与路径提升；三角网格角亏和离散 Gauss–Bonnet |
| 分析与微分方程 | 傅里叶潮汐、复流海峡 | 有限 Fourier 展开；复数乘法的旋转与缩放 |
| 概率与统计 | 布朗三角洲、均值潮汐 | 有限网格的高斯增量路径；Bernoulli 样本均值 |
| 离散与计算 | 图桥群落、拟阵森林 | 非负加权最短路；K₄ 图拟阵的秩、森林与基 |
| 逻辑与基础 | 类型观测台、康托海岸 | 函数应用与复合的简单类型规则；Cantor 集的有限阶段 |
| 数值与优化 | 梯度盆地、运输沙洲 | 指定二次函数的梯度迭代；一维离散等质量最优运输 |
| 数学物理与应用 | 热流海岸、谱灯塔 | 周期热方程的 Fourier 模式；有限 Dirichlet 拉普拉斯本征模式 |

## 0.2 联岛实验

| 联岛工作台 | 可以核对的数学联系 | 关键边界 |
| --- | --- | --- |
| 傅里叶与热流 | 同一组有限 Fourier 系数、周期热解及能量衰减 | 周期 2π、扩散系数 1；常数模式保持 |
| 图与同调 | K₄ 子复形的边界矩阵、周期、边界与 F₂ 同调 | 填满四个三角面得到球面边界，不是填实的三维单形 |
| 复数与覆盖 | 圆周映射 z↦zⁿ、连续路径提升与终点置换 | 起点和累积角决定提升；中途路径不冒充闭路 |
| 运输与分布函数 | 一维离散概率的 W₁ 运输费用等于两条 CDF 的面积差积分 | 不是 W₂，也不直接推广到高维 |
| 理想与零点 | Fₚ[x] 的 gcd、Bézout 恒等式、生成理想与共同零点 | 没有 Fₚ 有理根不能推出生成单位理想 |
| 对称与表示 | D₄ 的复数乘法/共轭动作与实二维矩阵表示 | 反射是实线性；零向量像相同不代表群元素相同 |

每个工作台同时显示计算、可操作的反例、来源定位和适用条件。见[联岛课程与来源记录](docs/connection-curriculum.md)、[独立审查](docs/connections-review.md)及[教师指南的联岛活动](docs/teacher-guide.zh-CN.md)。这些课程联系保留在教育层，不自动成为本体关系或形式证明。

## 使用

探索地图支持拖动、双指缩放、缩放按钮与方向键。聚焦地图后，用 `+` / `−` 缩放，`Home` 总览。岛屿目录、搜索和领域选择提供文字路径。手机可直接用当前岛的快捷入口打开实验。

每个实验的控件改变真实模型参数或离散构造；图形放大、文字读数及表格用于补充小屏阅读。探索标记表示操作经历，不表示已证明或通过测评。阅读“这幅图的边界”，把可视观察与数学结论的条件区分开来。

航记保存在当前浏览器的 localStorage 中。跨设备请导出 JSON 后导入；同一岛保留时间较新的记录，时间相同保留本机版本，其余记录不删除。未知课程的记录仍可保留和导出。清理站点数据会清除本机航记；备份文件不受影响。

联岛实验记录另存于本机浏览器：点击保存时记录当时的参数、计算结果、观察文字、模型版本和时间。可导出 JSON 备份或 Markdown 阅读稿；JSON 导入按记录 ID 合并，已有同 ID 记录保留本机版本。上限为 **500 条记录**；备份或合并结果超过 5 MiB、格式错误或合并后超限时，导入整体拒绝，原记录保留。达到上限后先导出备份，再删除不需要的本机记录。浏览器存储也有容量限制，保存不可用时界面会提示。

**分享只分享实验入口。** 链接包含工作台与语言，不携带当前参数、计算结果或私人笔记。打开已存记录的入口也不会自动恢复其参数；需要依据记录手动复现。两类笔记的 JSON 格式不同，请从相应的航记或实验记录入口导入。它们均不写回本体，也不上传到应用服务器。

## 本地运行与构建

需要 Node.js 20.19+ 或 22.12+；本次使用 Node 24。已提交浏览器所需的数据快照，通常运行前端不需要重建 Python 图谱。

```bash
cd education
npm ci
npm run dev                 # http://localhost:4173
npm run build
npm run preview
npm test
```

构建产物位于 `education/dist/`，支持普通静态托管和子路径部署。请使用 HTTP 服务打开，不直接双击 `index.html`。安装完依赖并构建后，图谱、课程与实验可由本地服务器离线运行；外部文献链接需要网络。

0.2 的数学与交互验证见[联岛独立审查](docs/connections-review.md)；既有对象课堂的历史浏览器审查见[0.1 审查记录](docs/review.md)。测试数学不变量、跨语言课程完整性、ID 解析、全量节点与边的投影、导入合并和实际交互；测试通过不构成定理证明。

## 与本体如何独立成长

```text
本体 nodes / edges / bridges / layout / 双语桥梁报告
                      │ 只读、版本化投影
                      ▼
             education/public/data
                      │
         ┌────────────┴────────────┐
         ▼                         ▼
    完整图谱浏览器             稳定 coreId 引用
                                    │
                       课程 + 对象模型 + 生态美术
```

课程和海图布局是教育层资料，不能覆盖本体节点。完整图谱的坐标与关系忠实复制来源快照；示意地貌和策展虚线不写成关系。未检验的 MathCups 渐近类型标注继续保持未知，不因教学命名而自动完成类型化。

本体更新后，用 `npm run data:build` 生成新的教育投影，核查悬空引用、条目顺序哈希和变化的桥梁条件，再更新相关课程。构建脚本只写 `education/public/data`。教育模块也可以继续使用其明确注明的旧快照，本体不必等待课程更新。

`npm run verify:publication` 对照上游提交 `0b56806` 检查发布前已有的 7,314 个文件。开发期间，上游单独提交了根 README 项目名从 Mafh 到 Math 的修正；发布保留这项修改。原始工作基线 `66751e9` 及其修改前审计记录继续保留，不能声称两个版本的 README 字节相同。两份基线都是明确版本的交付审计，不是禁止本体继续变化的持续集成门禁。详见[审查记录](docs/review.md)与[数据契约](docs/data-contract.md)。
